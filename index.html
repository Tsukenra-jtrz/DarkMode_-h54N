APEX TEACH

Peran setiap file untuk membuat website:

HTML

Bertindak sebagai "tulang punggung" atau struktur dasar halaman. HTML mendefinisikan konten seperti judul, paragraf, gambar, dan tautan..

CSS

Mengatur "penampilan" atau estetika. Dengan CSS, Anda bisa mengubah warna, jenis font, tata letak, dan membuat desain yang responsif di berbagai perangkat.

JAVA SCRIPT

Memberikan "logika" dan interaktivitas. JS memungkinkan elemen halaman berubah secara dinamis, merespons klik pengguna, memvalidasi formulir, dan memuat data tanpa menyegarkan halaman.
